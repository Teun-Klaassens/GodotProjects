# Godot Projects

A collection of games and programming experiments I've built using Godot and GDScript.

These projects explore game mechanics, physics, procedural environments, and 2D and 3D development.

## Projects

### Thalassophobia

A first-person horror prototype set in a dark, flooded industrial environment.

I developed the project to experiment with atmosphere, lighting, underwater environments, and interactive 3D systems.

Key features:
- First-person player controller
- Underwater visual effects
- Environmental lighting and sound
- Interactive doors and environmental objects
- Custom tools for adjusting environment settings

[View project](thalassophobia/)

### Stacking Boxes

A 2D physics-based stacking game using Tetris-inspired blocks.

The goal is to stack objects while keeping the structure balanced.

Key features:
- RigidBody2D physics
- Random block spawning
- Camera movement based on stack height
- Predicted landing positions using a separate physics simulation

[View project](stacking-boxes/)

### Bouncy

A small 2D game built to experiment with physics, visual effects, and gameplay mechanics.

Key features:
- Ball and paddle interactions
- Collision-based gameplay
- 2D effects and shaders

[View project](bouncy/)

## Technologies

- Godot 4

- Shaders and materials

## Running the Projects

1. Install Godot 4.7 or a compatible version.
2. Clone or download this repository.
3. Open Godot and import the `project.godot` file inside the project you want to run.
4. Open the project and press F6 to run the current scene or F5 to run the main project.
